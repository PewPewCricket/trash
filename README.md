# TRASH: a simpler linux shell
Just slap this "shell" into your system and you can have one third the functionality of every other linux system!

# Features
Setting env vars by using: ``export VAR=VALUE``. <br>
Changing directories with ``cd``. <br>
Running executables.

I'm starting to feel like this isn't a very feature complete shell... Maybe I'll change that, who knows! <br>
